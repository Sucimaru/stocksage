StockSage on BNB Chain

AI stock research, sold on-chain. Pay USDC to a smart contract, get an analyst report — live market data plus a Gemini-written note, cached per ticker per day.

Price

0.05 USDC per report — if your wallet holds a SPACE ID Agent ID (50% off)
0.10 USDC per report — full price, no Agent ID

The discount is decided on-chain by the contract itself (priceFor() reads your Agent ID balance). A purchase unlocks that ticker's report for 24 hours.

How it works

  1. Ask the server for a quote: GET /quote?ticker=AAPL&buyer=0x…
  2. Approve exactly the quoted USDC amount to the StockSageAccess contract. Never unlimited.
  3. Call purchase("AAPL"). The contract pulls exactly the approved amount and records your purchase on-chain.
  4. Fetch GET /research?ticker=AAPL&buyer=0x… — the server verifies your purchase on-chain and serves the report.

Contracts (BNB Chain, chain 56)

  • StockSageAccess: 0xc6cf59c62b7c4d24DaFB221Ce642D0a1EF783bf6
  • USDC (Binance-Peg, 18 decimals): 0x8AC76a51cc950d9822D68b83fE1Ad97B32Cd580d
  • Agent ID (SPACE ID, ERC-721): 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F

Contract source: github.com/Sucimaru/stocksage (bnb-port/). Verified on BscScan after deploy. The owner can only withdraw collected USDC and change prices (holder price always below full price). No other owner powers; no fee, tax, mint, or blacklist.

Note: Binance-Peg USDC on BSC does not support EIP-3002, so payment is plain ERC20 approve + purchase — never a signed authorization.
